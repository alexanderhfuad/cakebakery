# Brielicious Bakery Monorepo

Monorepo untuk aplikasi Brielicious Bakery dengan frontend React + Vite dan backend Node.js.

## Struktur

- `frontend/` - Aplikasi React + Vite
- `backend/` - Server Node.js / Express

## Perintah umum

```bash
npm install
npm run dev          # frontend development
npm run dev:frontend  # frontend development
npm run dev:backend   # backend development
npm run build        # build semua paket
```

## Workspace

Root `package.json` mengelola `frontend` dan `backend` sebagai workspaces.
